# 노트북에서 이어서 작업하기

아이패드에서 하던 작업을 그램(윈도우)에서 그대로 이어받는 방법입니다.
코드도 문서도 전부 GitHub에 올라가 있으므로, 내려받기만 하면 됩니다.

---

## 1. 처음 한 번만: 프로그램 설치

| 프로그램 | 용도 | 받는 곳 |
|---|---|---|
| **Git** | 코드 내려받기·올리기 | https://git-scm.com/download/win |
| **Node.js** (LTS) | 개발 서버, 테스트 실행 | https://nodejs.org |
| **VS Code** | 코드 편집 | https://code.visualstudio.com |

Git 설치할 때 기본값 그대로 두면 됩니다. 설치가 끝났는지 확인:

```bash
git --version
node --version
```

두 줄 다 버전이 나오면 준비 끝입니다.

---

## 2. 프로젝트 내려받기

**PowerShell**이나 **Git Bash**를 열고, 프로젝트를 둘 폴더로 이동한 뒤:

```bash
cd C:\Users\사용자이름\Documents

git clone https://github.com/HojungCHOI/bara.git
cd bara
git checkout claude/test-coverage-analysis-2o18c7
```

> 마지막 줄이 중요합니다. 작업 내용이 `claude/test-coverage-analysis-2o18c7`
> 브랜치에 있어서, 이걸 빼먹으면 빈 화면을 보게 됩니다.

한글 파일 이름(`.claude/commands/스케치.md`)이 깨져 보이면 한 번만 실행하세요:

```bash
git config --global core.quotepath false
```

---

## 3. 실행해 보기

```bash
npm start
```

브라우저에서 **http://localhost:8080** 을 엽니다.

> 마이크는 `localhost` 또는 HTTPS에서만 열립니다.
> `index.html`을 파일로 직접 더블클릭하면 마이크도 안 되고 화면도 깨집니다.
> 반드시 `npm start`로 여세요.

테스트 실행:

```bash
npm test
```

`총 74개 중 74개 통과` 가 나오면 정상입니다.

---

## 4. VS Code로 열기

```bash
code .
```

또는 VS Code에서 `파일 → 폴더 열기`로 `bara` 폴더를 고릅니다.

---

## 5. Claude Code로 이어서 작업하기

노트북에 Claude Code를 설치하면, **아이패드에서 하던 맥락 그대로** 이어집니다.

```bash
npm install -g @anthropic-ai/claude-code
cd C:\Users\사용자이름\Documents\bara
claude
```

프로젝트 폴더 안에서 실행하면 아래 파일들을 자동으로 읽습니다.

| 파일 | 담긴 내용 |
|---|---|
| `CLAUDE.md` | 이 프로젝트의 규칙 (배포 경로, 데이터 원칙, 주의할 점) |
| `sketch.md` | 지금까지의 구상과 그에 대한 분석 |
| `.claude/commands/스케치.md` | `/스케치` 명령 |
| `docs/` | 배포 방법, 데이터 형식 |

그래서 처음부터 설명할 필요 없이 **"성경헬퍼 이어서 하자"** 라고만 해도 됩니다.

`/스케치 내용` 명령도 노트북에서 그대로 씁니다. (저장소에 들어 있어서 따라옵니다)

---

## 6. 작업한 내용 올리기

노트북에서 고친 뒤:

```bash
npm test                  # 먼저 깨진 데 없는지 확인
git add -A
git commit -m "무엇을 바꿨는지 한 줄로"
git push
```

아이패드에서 다시 이어받을 때는 `git pull` 하면 됩니다.

> **주의:** 노트북과 아이패드 양쪽에서 고친 뒤 push하면 충돌이 납니다.
> 작업을 시작하기 전에 항상 `git pull` 부터 하는 습관을 들이세요.

---

## 7. 서버에 올리기

```bash
npm run dist
```

`dist/` 폴더가 만들어집니다. 그 **안의 파일들**을 FTP로
서버의 `/app/biblehelper/` 에 올리면 `https://signes.kr/app/biblehelper/` 로 열립니다.

자세한 절차는 [`DEPLOY.md`](DEPLOY.md) 를 보세요.

---

## 자주 막히는 곳

**`npm` 을 찾을 수 없다고 나옴**
→ Node.js 설치 후 PowerShell을 껐다 다시 여세요. 환경변수가 새로 열린 창에만 반영됩니다.

**`git clone` 할 때 로그인을 물어봄**
→ 공개 저장소라 로그인 없이 받아집니다. 물어본다면 주소 오타일 가능성이 높습니다.

**화면은 뜨는데 마이크 버튼이 안 눌림**
→ 파이어폭스는 음성인식을 지원하지 않습니다. 크롬이나 엣지로 여세요.

**바꾼 게 화면에 반영되지 않음**
→ `Ctrl + Shift + R` (강력 새로고침)

**`npm test` 가 실패함**
→ 그 자체로 정보입니다. 어느 검사가 깨졌는지 알려주므로, 그대로 Claude에게 붙여넣으세요.
