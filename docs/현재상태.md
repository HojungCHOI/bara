## 더 해볼 만한 것

- **노래 인식 정확도** — Web Speech API는 말소리 기준이라 부르는 찬송은
  잘 못 알아듣는다. 음향 지문(audio fingerprinting) 방식이면 가능하지만
  찬송가 음원 데이터베이스가 따로 필요해서 규모가 훨씬 커진다.
  현실적인 개선은 인도자의 **말**을 잘 잡는 쪽에 집중하는 것.
- **오프라인 동작** — Service Worker를 붙이면 인터넷이 끊겨도 열린다.
  단, 음성인식 자체가 서버를 쓰므로 마이크 기능은 여전히 인터넷이 필요하다.
- **이전 구절 이어보기** — 목사님이 "17절도 보겠습니다" 할 때
  직전에 연 장을 기억해 이어서 열어 주기.
- **글씨 더 크게 / 화면 고정** — 예배 중 실제로 써 보고 조정.
