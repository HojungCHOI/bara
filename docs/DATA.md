# 데이터 형식

이 앱은 찬송가 가사와 성경 본문을 **저장소에 포함하지 않는다.** 두 가지 이유가 있다.

1. **저작권** — 개역개정·새번역 등 대부분의 한글 성경과 새찬송가 가사는 저작권이 있다.
2. **판본 차이** — 새찬송가(2006)와 통일찬송가는 **번호 체계가 다르다.**
   번호를 앱에 박아 두면 교회에 따라 엉뚱한 장을 열어 주게 된다.

그래서 사용자가 본인 교회에서 쓰는 판본을 직접 불러오는 구조로 만들었다.
불러온 데이터는 **그 기기의 브라우저에만** 저장되고 서버로 전송되지 않는다.

---

## 찬송가

설정 화면에서 JSON 또는 CSV 파일을 불러온다. 아래 세 형식을 모두 지원한다.

### 1. CSV (가장 간단함)

```csv
number,title,lyrics
1,만복의 근원 하나님,만복의 근원 하나님 온 백성 찬송 드리고
305,나 같은 죄인 살리신,"나 같은 죄인 살리신, 주 은혜 놀라워"
```

- 첫 칸이 숫자가 아니면 헤더 줄로 보고 건너뛴다.
- 쉼표가 들어가는 가사는 큰따옴표로 감싼다.
- 서식 파일: [`data/hymns.template.csv`](../data/hymns.template.csv)

### 2. JSON 배열

```json
[
  { "number": 1, "title": "만복의 근원 하나님", "lyrics": "만복의 근원 하나님 온 백성..." }
]
```

`{ "hymns": [ ... ] }` 처럼 한 겹 감싼 형태도 읽는다.
한글 키(`장`, `제목`, `가사`)도 그대로 인식한다.

### 3. JSON 객체 (번호를 키로)

```json
{
  "1": { "title": "만복의 근원 하나님", "lyrics": "만복의 근원..." },
  "305": { "title": "나 같은 죄인 살리신", "lyrics": "나 같은 죄인..." }
}
```

### 가사를 넣지 않아도 된다

`lyrics`를 비워 두고 번호와 제목만 넣어도 된다.
이 경우 "찬송가 305장" 같은 **번호 인식**은 완전히 동작하고,
가사 한 소절로 찾는 기능만 쓸 수 없다.

저장 공간(localStorage, 대개 5MB)이 부족하다는 안내가 나오면
가사를 1절만 넣거나 제목만 넣으면 된다.

## 성경 본문

JSON 파일 하나로 불러온다. 구조는 `권 이름 → 장 → 절 → 본문`이다.

```json
{
  "요한복음": {
    "3": {
      "16": "하나님이 세상을 이처럼 사랑하사 ...",
      "17": "하나님이 그 아들을 세상에 보내신 것은 ..."
    }
  },
  "시편": {
    "23": { "1": "여호와는 나의 목자시니 ..." }
  }
}
```

- 권 이름은 [`data/books.json`](../data/books.json)의 `name` 값과 **정확히 같아야 한다.**
  (예: `요한복음`, `사무엘상`, `요한계시록`)
- 장·절 번호는 문자열 키로 넣는다.
- 전체 성경이 5MB를 넘으면 저장에 실패할 수 있다. 신약만 넣는 것도 방법이다.

### 본문이 없어도 쓸 수 있다

본문 파일을 넣지 않아도 **"요한복음 3장 16절"을 인식해 어디를 펴야 하는지 알려 준다.**
종이 성경책을 쓰는 경우에는 이것만으로 충분하다.
본문을 넣으면 구절 내용까지 화면에 표시된다.
