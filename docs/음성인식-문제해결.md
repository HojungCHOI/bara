# 아이패드에서 음성인식이 안 될 때

앱 **설정 화면의 "진단하기"** 버튼을 먼저 눌러 보세요.
무엇이 막고 있는지 앱이 직접 확인해서 알려 줍니다.

아래는 원인별 설명입니다. 위에서부터 흔한 순서입니다.

---

## 0. 먼저 확인: 어떤 주소로 열었나요?

**이게 가장 흔한 원인입니다.**

음성인식은 **HTTPS 주소**에서만 동작합니다. 다음은 전부 안 됩니다.

| 이렇게 열면 | 결과 |
|---|---|
| `index.html` 파일을 직접 열기 (`file://`) | ✕ 마이크 권한 요청 자체가 안 뜸 |
| `http://` 로 시작하는 주소 | ✕ 차단됨 |
| 아이패드에서 파일 앱으로 열기 | ✕ |
| `https://` 로 시작하는 주소 | ✓ |
| `http://localhost:8080` (개발 중일 때만) | ✓ |

아직 서버에 올리지 않았다면 아이패드에서는 **테스트할 방법이 없습니다.**
`https://signes.kr/app/biblehelper/` 에 올린 뒤에 열어야 합니다.
(올리는 방법은 [`DEPLOY.md`](DEPLOY.md))

---

## 1. 사파리로 열어야 합니다

**아이패드·아이폰에서 음성인식이 되는 브라우저는 사파리뿐입니다.**

크롬, 엣지, 웨일, 파이어폭스, 그리고 카카오톡·인스타그램 안에서 열리는
브라우저는 **전부 안 됩니다.** 아이폰·아이패드의 다른 브라우저들은
겉모습만 다를 뿐 속은 사파리와 같은 엔진을 쓰지만,
애플이 음성인식 기능만은 사파리에만 열어 두었기 때문입니다.

카카오톡으로 받은 링크를 눌러서 열었다면, 오른쪽 위 `⋯` → **"사파리로 열기"** 를 누르세요.

---

## 2. 받아쓰기가 켜져 있어야 합니다

아이패드 자체의 받아쓰기 기능이 꺼져 있으면 **오류 메시지도 없이 조용히 아무 일도 일어나지 않습니다.**
이 경우가 제일 헷갈립니다.

> **설정 → 일반 → 키보드 → "받아쓰기 켬"**

스위치가 꺼져 있으면 켜 주세요. 켠 뒤에는 사파리를 완전히 껐다가 다시 여세요.

---

## 3. 마이크 권한을 허용해야 합니다

사파리 주소창 왼쪽의 **«АА»** 버튼 → **웹사이트 설정** → **마이크** → **허용**

한 번 "거부"를 누르면 다시 물어보지 않으므로, 여기서 직접 바꿔야 합니다.

---

## 4. 인터넷이 연결되어 있어야 합니다

음성인식은 기기 안에서 처리되는 것이 아니라 **애플 서버로 보내서 처리**합니다.
와이파이나 셀룰러가 끊기면 동작하지 않습니다.

교회 와이파이가 불안정하다면 이 점을 염두에 두세요.

---

## 5. 그래도 안 될 때

- 사파리를 완전히 종료한 뒤 다시 열기
  (화면 아래에서 위로 쓸어올려 사파리 카드를 위로 밀어 버리기)
- 아이패드 재시동
- 저전력 모드가 켜져 있으면 꺼 보기
- iPadOS 14.5 이상인지 확인 (설정 → 일반 → 정보)

---

## 원래부터 안 되는 것

**노래는 잘 못 알아듣습니다.**

Web Speech API는 **말소리**를 받아쓰도록 만들어져서,
회중이 부르는 찬송을 그대로 알아듣는 정확도는 낮습니다.
음이 길게 늘어지고 반주가 섞이면 더 떨어집니다.

그래서 이 앱은 인도자가 **"찬송가 305장 부르겠습니다"라고 말할 때** 가장 잘 동작합니다.
가사 검색은 보조 수단으로 생각해 주세요.

마이크가 잘 안 잡히는 상황을 대비해 **직접 입력 칸**을 항상 열어 두었습니다.
"요한복음 3장 16절"처럼 치면 똑같이 동작합니다.
