# 바라 · 성경 찬송가 헬퍼

예배 중에 들리는 말을 마이크로 듣고, 해당 **찬송가 장**이나 **성경 본문**을 자동으로 찾아
큰 글씨로 띄워 주는 웹앱입니다.

> "지금 몇 장이지?", "어디를 펴야 하지?" 하고 헤매는 시간을 없애기 위해 만들었습니다.

## 무엇을 하나

마이크로 들은 말을 세 갈래로 해석합니다.

| 들린 말 | 결과 |
|---|---|
| "찬송가 305장 부르겠습니다" | 305장을 엽니다 |
| "찬송가 삼백오장" | 한자어 수사를 숫자로 바꿔 305장을 엽니다 |
| "요한복음 3장 16절" | 해당 구절 위치를 엽니다 |
| "오늘 본문은 창세기 일장 일절입니다" | 문장 속에서 참조만 뽑아냅니다 |
| "잃었던 생명 찾았고" (가사 일부) | 가사 유사도로 찬송가 후보를 보여 줍니다 |

## 바로 써 보기

배포 주소: `https://signes.kr/app/biblehelper`

1. 마이크 버튼을 누르고 권한을 허용합니다.
2. 찬송가 번호나 성경 구절을 말합니다.
3. 결과가 큰 글씨로 나타납니다.

마이크가 안 되는 상황에서는 아래 입력 칸에 직접 쳐도 똑같이 동작합니다.

## 알아 두어야 할 한계

- **노래는 잘 못 알아듣습니다.** Web Speech API는 말소리에 맞춰져 있어서,
  회중이 부르는 찬송을 그대로 인식하는 정확도는 낮습니다.
  인도자가 **"찬송가 305장 부르겠습니다"라고 말할 때** 가장 잘 동작합니다.
  가사 검색은 보조 수단으로 쓰세요.
- **HTTPS에서만 마이크가 열립니다.** (`localhost`는 예외)
- **브라우저마다 다릅니다.** iOS/iPadOS 사파리, 크롬, 엣지에서 동작합니다.
  파이어폭스는 음성인식을 지원하지 않아 직접 입력만 됩니다.
- 사파리는 음성인식을 스스로 끊는 일이 잦아서, 끊기면 자동으로 다시 켜도록 해 두었습니다.
- **아이패드에서는 사파리로만 됩니다.** 크롬·웨일·카카오톡 내부 브라우저는 안 됩니다.
  안 될 때는 설정 화면의 **"진단하기"** 를 누르면 원인을 짚어 줍니다.
  자세한 내용은 [`docs/음성인식-문제해결.md`](docs/음성인식-문제해결.md).

## 찬송가·성경 데이터 넣기

앱에는 성경 66권의 **이름과 장 수**만 들어 있습니다.
찬송가 가사와 성경 본문은 판본마다 저작권자가 다르고,
무엇보다 **새찬송가와 통일찬송가는 번호가 서로 달라서** 미리 넣어 두지 않았습니다.

설정 화면에서 본인 교회 판본을 불러오면 **그 기기에만** 저장됩니다.
자세한 형식은 [`docs/DATA.md`](docs/DATA.md)를 보세요.

본문을 넣지 않아도 "요한복음 3장 16절"을 인식해 **어디를 펴야 하는지**는 알려 줍니다.
종이 성경책을 쓰신다면 이것만으로 충분합니다.

## 개발

빌드 도구가 없습니다. 순수 HTML/CSS/JavaScript(ES 모듈)라 파일을 열면 바로 돌아갑니다.

```bash
npm start          # 개발 서버 → http://localhost:8080
npm test           # 테스트 74건
npm run dist       # 배포용 dist/ 만들기
```

셋 다 node 만 있으면 윈도우·맥·리눅스에서 똑같이 동작합니다.
마이크는 `localhost` 또는 HTTPS 에서만 열리므로,
`index.html` 을 더블클릭하지 말고 `npm start` 로 여세요.

### 구조

```
index.html              화면
css/style.css           스타일 (어두운 예배당 기준, 큰 글씨)
js/app.js               전체 흐름 연결
js/speech.js            Web Speech API 래퍼 (자동 재시작 포함)
js/korean-number.js     한국어 수사 → 숫자 ("삼백오" → 305)
js/bible-ref.js         성경 참조 파서 ("요 3:16" → 요한복음 3:16)
js/hymn.js              찬송가 번호 파서
js/search.js            2-gram 유사도 검색 (받아쓰기 오차 허용)
js/store.js             localStorage 저장 + 파일 형식 파싱
data/books.json         성경 66권 이름·약칭·장 수 (본문 없음)
test/run.js             테스트 (의존성 없음)
scripts/serve.js        개발 서버
scripts/build-dist.js   배포용 파일 추리기
```

### 배포

정적 파일만 있으므로 웹서버에 그대로 올리면 됩니다.
모든 경로가 상대경로라 `https://signes.kr/app/biblehelper` 같은
**하위 경로에 두어도 그대로 동작합니다.**

```bash
npm run dist
```

`dist/` 폴더가 만들어집니다. 그 **안의 파일들**을 FTP로 서버의
`/app/biblehelper/` 에 올리면 됩니다. 자세한 절차는 [`docs/DEPLOY.md`](docs/DEPLOY.md).
